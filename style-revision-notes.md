# Style Revision Notes (from Visual Review)

## Key Changes Needed
1. **Asymmetric hero** — push away from centered SaaS layout, use bold color-blocking
2. **Stronger brand identity** — MC seal needs to feel like a trust mark, not plain text
3. **Better worker imagery** — use trade-specific photos (tools, workshops) not corporate headshots
4. **Signature motif** — terracotta gradient borders, seal-like verification marks across sections
5. **Varied card rhythm** — less uniform grid, more hand-crafted stagger

## What's Working
- Sand background, terracotta CTAs, DM Serif headlines
- Trust-focused Spanish copy
- Rounded stone cards
- Calm/premium spacing
- Filter pills with counts
- Pricing comparison table
